# Projeto

## Estado atual

GraviCodex é um template documental para engenharia com Codex e/ou Antigravity. O artefato principal é Markdown. Há um validador local em Python e uma rotina de CI; ainda não há aplicação de produto.

## Objetivo

Fornecer instruções reutilizáveis, navegação por tarefa e registros curtos que permitam executar e retomar trabalho com menos recuperação desnecessária de contexto.

## Contrato desta base

- Público: pessoas e agentes trabalhando no mesmo repositório.
- Idioma da documentação: português; caminhos e identificadores técnicos podem usar inglês.
- Restrições: entrada curta, informação com proprietário claro, ausência de stack presumida.
- Pronto quando: uma tarefa consegue localizar seu contexto, executar a mudança e apresentar validação verificável.
- Fora de escopo: prometer redução fixa de tokens, impor fornecedor de modelos ou configurar serviços sem uma necessidade do produto.

## Ao criar um produto

Substitua este perfil por: problema, usuário, resultado observável, escopo, restrições e estado real. Atualize [comandos](commands.md) e [mapa](map.md) com caminhos existentes. Requisitos ainda ausentes devem aparecer como pendências explícitas, não como decisões tomadas.

Detalhes voláteis de tarefas pertencem a [registros de trabalho](../tasks/README.md), não a este perfil.
